# Security

Report a vulnerability through
[Report a vulnerability](https://github.com/andriykohut/hawse/security/advisories/new)
rather than a public issue. Only the maintainer can read what is sent there.

Say which version you tested, which end is affected, and how to reproduce it. A
config and a log help, as they do for any bug.

Fixes go into the latest release only. Older releases are not patched.
